# 配布と公開チェック

この配布は既存リポジトリの履歴を持たない、新規のクリーンなソースです。元のTask・Project・Review、秘密、ログ、会話、バックアップは含めません。合成テストのデータだけを使用します。元リポジトリを直接公開すると過去commit・削除済みファイル・実名や業務内容・認証設定も閲覧され得るため採用しません。

## 公開前

- [ ] 自作コードの公開権限と採用ライセンスを本人確認する。元のLICENSEが無いためMIT等を推測で付与しない。
- [ ] 提供ファイル一覧と全ファイルを確認し、個人記録・IP・メール・秘密・生成ログがないことを検査する。
- [ ] 新規Git履歴だけを作成する。元のremote、commit、Issue、個人設定をコピーしない。
- [ ] リポジトリ名・公開範囲を確認して初回公開する。公開後の削除で他者のコピーを取り消せない。
- [ ] 公開commit hashとGitHub Actions結果を記録する。

## 依存と権利

Pythonの追加pipパッケージ、Nodeパッケージ、第三者PowerShellモジュールはありません。Dockerベースは公式 `python:3.14-slim` のdigestを固定しています。Python、Debianの同梱ライセンス・通知はベースイメージ内に保持されます。本アプリのライセンスはそれらの権利を置き換えません。Docker製品とCopilotの契約・会社利用条件は会社の既存承認を確認します。ベース更新はdigestと全体検証を同時に更新します。

画像等の権利未確認アセットを除外し、配布用背景は単純な自作SVGに置き換えています。OAuth/Slack/Teams設定、.env、秘密、外部カレンダーサービス、Codex実行手順を含めません。

## 会社PC受入

- Docker Linux containers/Compose、PowerShell実行・署名ポリシー、承認済みブラウザ。
- localhost限定公開と同一PC利用者のアクセス境界。
- 起動・二重起動・他アプリのport競合・停止・再開。
- volume永続性、停止バックアップ、復元前コピー、復元後読戻し。
- 通知許可、Windows集中モード、スリープ・ログアウト・復帰、ブラウザfallback。
- 会社データをGitに送信しない。ZIPを標準とし、データ・バックアップをソース外へ保存。
- Copilotへ送信可能な会社情報の範囲を確認。Teamsは初回配布外。

Windowsの実動作はUbuntuだけでは確定できません。CIのPowerShell構文検査と会社PCでの受入検査を区別します。
